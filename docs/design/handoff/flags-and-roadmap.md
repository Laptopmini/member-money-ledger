# Feature flags and roadmap

Design everything below now, even if it ships later. Each flag hides its UI completely when off.

| Flag | Default | What it shows | Status |
|---|---|---|---|
| `tax-set-aside` | on | Tax set-aside card, incentive line, Mark as set aside | Building now |
| `auth-required` | on | Login, session warning, sign out | Building now |
| `merchant-rules` | off | "Apply to N other <merchant> transactions?" prompt; rules list in settings later | Next |
| `category-suggestions` | off | AI suggestion chips on uncategorized rows (local or cloud model; suggestion only) | Next |
